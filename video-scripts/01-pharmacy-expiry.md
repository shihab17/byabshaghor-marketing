# ভিডিও স্ক্রিপ্ট: "গত মাসে কত টাকার ওষুধ ফেলে দিলেন?"

**সিরিজ:** Pharmacy — pain point video #1
**ফরম্যাট:** Short-form, ৩০–৪০ সেকেন্ড (TikTok / Reels / YouTube Shorts)
**টার্গেট:** ফার্মেসি মালিক
**মূল pain point:** মেয়াদ শেষ হয়ে ওষুধ নষ্ট — মাসিক হাজার হাজার টাকার ক্ষতি
**Hero feature:** মেয়াদ অ্যালার্ট + ব্যাচ-ভিত্তিক স্টক
**CTA:** ফ্রি ট্রায়াল — লিংক bio-তে

---

## Scene 1 — Hook (০–৩ সে)

**Visual:** হাতে expired ওষুধের স্ট্রিপ/বাক্স → সরাসরি বিনে ফেলে দেওয়া। Close-up shot।

**Voiceover:**
> গত মাসে কত টাকার ওষুধ মেয়াদ শেষে ফেলে দিয়েছেন?

**Text overlay (বড়, মাঝখানে):**
```
গত মাসে কত টাকার ওষুধ ফেলে দিয়েছেন?
```

> নোট: প্রথম ৩ সেকেন্ডেই প্রশ্ন — scroll আটকানোই কাজ।

## Scene 2 — Pain জমানো (৩–১০ সে)

**Visual:** মালিক shelf থেকে ৪–৫টা expired বাক্স নামিয়ে মাথা নিচু করে দেখছে / হিসাব করছে।

**Voiceover:**
> ফার্মেসির মালিকরা প্রতি মাসে হাজার হাজার টাকার ওষুধ নষ্ট করেন। শত শত ওষুধের মেয়াদ মনে রাখা — অসম্ভব।

**Text overlay:**
```
মাসে হাজার হাজার টাকার ক্ষতি
সব মেয়াদ মনে রাখা অসম্ভব
```

## Scene 3 — Turn (১০–১৩ সে)

**Visual:** ফোন স্ক্রিনে cut — ব্যবসা ঘর dashboard।

**Voiceover:**
> কিন্তু যদি মেয়াদ শেষের ৩০ দিন আগেই জানিয়ে দিতো কেউ?

## Scene 4 — Solution demo (১৩–২৮ সে)

**Visual:** স্ক্রিন রেকর্ডিং, ধীরে ধীরে —

1. Dashboard → **"মেয়াদ শেষ"** card — ২ সেকেন্ডে zoom (কত দিনের ভেতরে কতগুলো পণ্য)
2. Card-এ tap → **ব্যাচ-ভিত্তিক লিস্ট** — কোন ওষুধ, কোন ব্যাচ, কত দিন বাকি
3. লিস্ট scroll — লাল mark-ওয়ালা আইটেম আগে

**Voiceover:**
> ব্যবসা ঘর-এ ড্যাশবোর্ডেই দেখে দেয় — কোন ওষুধের মেয়াদ কবে শেষ, কোন ব্যাচ আগে বিক্রি করতে হবে। মেয়াদ শেষের আগেই বেচে ফেলুন — ক্ষতি নেই।

**Text overlay:**
```
মেয়াদের আগেই অ্যালার্ট
ব্যাচ ধরে স্টক দেখুন
```

## Scene 5 — CTA (২৮–৩৩ সে)

**Visual:** ফোনে অ্যাপের home + "ব্যবসা ঘর" লোগো/নীল icon।

**Voiceover:**
> আপনার ফার্মেসির হিসাব এবার ফোনেই। ফ্রি ট্রায়াল — লিংক bio-তে।

**End card:**
```
ব্যবসা ঘর — আপনার ব্যবসা, এক জায়গায়
ফ্রি ট্রায়াল → bio-তে লিংক
```

## Production notes

- Demo-তে আসল ডেটা — "নাপা ৫০০", "প্যারাসিটামল" টাইপ real ওষুধের নাম (relate করে)
- Screen recording-এ স্ক্রল ধীরে — viewer পড়ার সময় পায়
- Scene 1 আসল ফার্মেসিতে শুট করা ভালো; না পেলে shelf-এ বাক্স সাজিয়ে close-up যথেষ্ট
- Voiceover না থাকলেও চলবে (text overlay যথেষ্ট); voice থাকলে retention বাড়ে
- তিন প্ল্যাটফর্মে একই ভিডিও — শুধু caption-এ hashtag প্ল্যাটফর্ম অনুযায়ী adjust
